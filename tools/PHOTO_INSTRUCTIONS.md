# Ночной поиск фото товаров (lamerel.ge)

Репозиторий: grvm7gcz4n-png/lamerel-shop (ветка main). Сайт собирается `python3 tools/build.py` из products.json.
Фото подключаются ССЫЛКОЙ (hot-link), файлы не скачиваем. Владелица магазина разрешила брать фото с официальных
сайтов брендов и у официальных дистрибьюторов.

## Что сделать
1. `python3 -c` → список товаров из products.json, у которых нет поля img, СНАЧАЛА stock>0, затем остальные.
   Для каждого есть brand, name (англ.), name_ru, vol, barcode.
2. Для каждого товара найти фото упаковки ИМЕННО ЭТОГО товара (тот же продукт, линейка, по возможности объём):
   - WebSearch: «<бренд> <название> <объём>» и/или штрихкод; открыть страницу официального сайта бренда или
     крупного магазина (официальный сайт → официальный дистрибьютор → крупный ритейлер) через WebFetch и взять
     прямую ссылку на картинку товара (https, .jpg/.png/.webp, лучше белый фон).
   - Приоритетные бренды (больше всего без фото): Kérastase, GIGI, Alfaparf Milano, L'Oréal Professionnel, Keune,
     BRAE, pHformula, PUSY, Philip Martin's, CHI, ZO Skin Health, Barba Italiana, Dermalogica, Charlotte Tilbury, Dior.
   - НЕ брать: фото с людьми, коллажи, баннеры, фото другого товара/цвета/оттенка, картинки с водяными знаками.
   - Если не уверен, что это тот же товар, — НЕ ставить, записать в отчёт.
3. Найденное дописать в tools/photo_found.json: "<id>": {"url": "...", "src": "<домен>", "match": "<название на сайте>"}.
   build.py сам подставит эти ссылки. id из tools/photo_rejected.json не трогать.
4. Каждые ~50 найденных: `python3 tools/build.py`, `git add -A && git commit`, `git pull --rebase origin main` (при конфликте
   в products.json/index.html — пересобрать build.py и продолжить rebase), `git push origin main`.
5. Товары без брендовых фото (косметички, очки, украшения, заколки «LamereL Select», сумки Dior/Chanel/Bvlgari,
   Charlotte Tilbury bag/зеркало) — не искать, сразу в отчёт «нужно сфотографировать в салоне».
6. В конце: файл tools/photo_report.md — по-русски, коротко:
   - сколько фото добавлено (всего и в наличии), по брендам;
   - список товаров, для которых фото не найдено: бренд, название, почему (нет в интернете / несколько похожих вариантов
     / нужно уточнить оттенок или объём) — сгруппировать, чтобы владелице было легко помочь;
   - список «сфотографировать в салоне».
   Закоммитить и запушить.
Не менять ничего в Altegio. Не трогать секреты, воркеры, CNAME.
